pystac.extensions.product
=========================

The Product Extension exposes product packaging, timeliness, acquisition type,
and lifecycle status metadata on Items, Collections, Assets, and Item Asset
Definitions. Lifecycle status values are represented by
:class:`~pystac.extensions.product.ProductStatus`; Collection summaries accept
lists of those values.
