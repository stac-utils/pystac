# pystac-ext-grid

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Grid Extension](https://github.com/stac-extensions/grid).
This extension describes gridded data products by specifying the grid code (e.g. MGRS, MODIS, or other tiling schemes) that the data corresponds to.

## Supported versions

- [v1.1.0](https://stac-extensions.github.io/grid/v1.1.0/schema.json)
- [v1.0.0](https://stac-extensions.github.io/grid/v1.0.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-grid** v1.1.0 corresponds to the [v1.1.0](https://github.com/stac-extensions/grid/releases/tag/v1.1.0) release of the **grid** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
