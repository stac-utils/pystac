# pystac-ext-pointcloud

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Point Cloud Extension](https://github.com/stac-extensions/pointcloud).
This extension provides fields for describing point cloud data, including point count, encoding, density, schemas, and statistics.

## Supported versions

- [v1.0.0](https://stac-extensions.github.io/pointcloud/v1.0.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-pointcloud** v1.0.0 corresponds to the [v1.0.0](https://github.com/stac-extensions/pointcloud/releases/tag/v1.0.0) release of the **pointcloud** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
