# pystac-ext-timestamps

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Timestamps Extension](https://github.com/stac-extensions/timestamps).
This extension provides fields for additional temporal metadata beyond the core datetime, including published, expires, and unpublished timestamps.

## Supported versions

- [v1.1.0](https://stac-extensions.github.io/timestamps/v1.1.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-timestamps** v1.1.0 corresponds to the [v1.1.0](https://github.com/stac-extensions/timestamps/releases/tag/v1.1.0) release of the **timestamps** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
