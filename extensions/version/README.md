# pystac-ext-version

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Versioning Indicators Extension](https://github.com/stac-extensions/version).
This extension provides fields for tracking version information and deprecation status of STAC items and collections, including links to predecessor and successor versions.

## Supported versions

- [v1.2.0](https://stac-extensions.github.io/version/v1.2.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-version** v1.2.0 corresponds to the [v1.2.0](https://github.com/stac-extensions/version/releases/tag/v1.2.0) release of the **version** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
