# pystac-ext-scientific

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Scientific Citation Extension](https://github.com/stac-extensions/scientific).
This extension provides fields for linking STAC items and collections to scientific publications, including DOIs and bibliographic citations.

## Supported versions

- [v1.0.0](https://stac-extensions.github.io/scientific/v1.0.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-scientific** v1.0.0 corresponds to the [v1.0.0](https://github.com/stac-extensions/scientific/releases/tag/v1.0.0) release of the **scientific** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
