# pystac-ext-eo

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Electro-Optical Extension](https://github.com/stac-extensions/eo).
This extension provides fields for describing electro-optical sensor data, including spectral band information, cloud cover, and snow cover.

## Supported versions

- [v1.1.0](https://stac-extensions.github.io/eo/v1.1.0/schema.json)
- [v1.0.0](https://stac-extensions.github.io/eo/v1.0.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-eo** v1.1.0 corresponds to the [v1.1.0](https://github.com/stac-extensions/eo/releases/tag/v1.1.0) release of the **eo** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
