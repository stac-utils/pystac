# pystac-ext-themes

[PySTAC](https://pypi.org/project/pystac/) extension package for the
[Themes Extension](https://github.com/stac-extensions/themes).
This extension describes controlled vocabularies and concepts used to classify
Catalogs, Collections, and Items.

## Supported versions

- [v1.0.0](https://stac-extensions.github.io/themes/v1.0.0/schema.json)

## Versioning

This package's version corresponds to the version of the extension specification it
targets. When we release updates to the package code without changing the target
extension version, we use
[post releases](https://packaging.python.org/en/latest/discussions/versioning/#post-releases),
e.g. `1.0.0.post1`.
