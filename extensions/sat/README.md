# pystac-ext-sat

[PySTAC](https://pypi.org/project/pystac/) extension package for the [Satellite Extension](https://github.com/stac-extensions/sat).
This extension provides fields for describing satellite-specific metadata, including orbit state vectors, relative orbit numbers, and platform-specific identifiers.

## Supported versions

- [v1.0.0](https://stac-extensions.github.io/sat/v1.0.0/schema.json)

## Versioning

This package's MAJOR and MINOR versions match the version of the extension itself, e.g. **pystac-ext-sat** v1.0.0 corresponds to the [v1.0.0](https://github.com/stac-extensions/sat/releases/tag/v1.0.0) release of the **sat** extension.
When we release updates to the package code without changing the target extension version, we use [PATCH releases](https://packaging.python.org/en/latest/discussions/versioning/#valid-version-numbers).
